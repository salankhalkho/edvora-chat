POST

https://edvora.chat/api/chat/message

Send student inquiries and receive intelligent AI answers, classified admission intents, and dynamic follow-up chips. 


                            


                            
                            

                                

                            


                            
                            

                                

                            


                            
                            

                                

                            

                        


                        
                        

                            

                                
                                    Request Headers & Body (JSON)
                                
                                

                                    
Content-Type: application/json

                                    
bot_token (required): Institutional Chatbot Token.

                                    
message (required): Student inquiry text string.

                                    
visitor_id (optional): Device UUID or student ID for conversational memory.

                                    
department_id (optional): Scope response to specific department.

                                

                            


                            

                                
                                    Response Payload Structure
                                
                                

                                    
status: "success" or "error"

                                    
data.reply: Fully synthesized institutional AI answer.

                                    
data.intent: Classified student intent (e.g. admission_deadline, tuition_fee).

                                    
data.quick_chips: Array of contextual follow-up chip strings.

                                    
data.confidence: Confidence score (0.0 to 1.0).

                                

                            

                        

                    


                    
                    

                        

                            🔄
                            

                                Outbound Lead & Event Webhooks
                            

                        

                        

                            Edvora automatically dispatches signed HTTPS POST payloads to your endpoint whenever a prospective student provides contact information, books a campus tour, or requests a counselor callback.
                        


                        

                            

                                
                                    Webhook Events Triggered
                                
                                
    
                                    
  • lead.captured — Student contact info submitted
    • 
                                    
  • callback.requested — Urgent counselor phone callback requested
    • 
                                    
  • tour.scheduled — Campus visit appointment booked
    • 
                                    
  • scholarship.evaluated — Eligibility evaluation submitted
    • 
                                

                            


                            

                                
                                    Webhook Payload Sample (JSON)
                                
                                
{
  "event": "lead.captured",
  "timestamp": "2026-08-21T10:30:00Z",
  "data": {
    "student_name": "Jordan Smith",
    "email": "jordan.smith@example.com",
    "phone": "+1 (555) 234-5678",
    "department": "Admissions & Enrollment",
    "program_interest": "Computer Science (BSc)",
    "lead_score": 85,
    "lead_type": "high_intent"
  }
}

                            

                        

                    


                    
                    

                        
                            HTTP Response Codes & Error Handling
                        
                        

                            

                                
                                    

                                        Status Code
                                        Meaning
                                        Description
                                    

                                
                                
                                    

                                        200 OK
                                        Request Successful
                                        Inference completed and structured reply returned.
                                    

                                    

                                        400 Bad Request
                                        Invalid Payload
                                        Missing bot_token or empty message field.
                                    

                                    

                                        401 Unauthorized
                                        Invalid Token
                                        The provided chatbot token does not exist or is disabled.
                                    

                                    

                                        429 Rate Limited
                                        Quota Exceeded
                                        Exceeded plan messages quota. Upgrade plan in Billing.
                                    

                                    

                                        500 Internal Error
                                        Server Error
                                        LLM upstream gateway error; automatic fallback will be attempted.
