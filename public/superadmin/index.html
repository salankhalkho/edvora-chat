💡 Configuration Quick Reference
  • Google Workspace / Gmail: Use smtp.gmail.com on port 587 (TLS). Generate an App Password in your Google Account security settings (2FA required).
  • SendGrid: Use smtp.sendgrid.net, port 587, username apikey, and password is your SendGrid API key.
  • Amazon SES: Use your region endpoint (e.g. email-smtp.us-east-1.amazonaws.com), port 587 (TLS) or 465 (SSL), with SES SMTP credentials.
  • VPS Firewall Notice: Outgoing connections to port 587 / 465 must be allowed by outbound network egress rules.
